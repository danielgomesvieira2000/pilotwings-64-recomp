# Drive the port from boot into a Hang Glider test, without a pad.
#
# Times are seconds since the game's first input poll. Each line is
#
#     <start> <end> <buttons> [stick_x stick_y] [# note]
#
# with the stick in the N64's own range (about +/-80), and lines overlap freely.
# See src/testdrive.cpp. The port's stderr transcript names each game state as
# it is entered, which is what tells you which press landed.
#
# The presses are repeated on purpose: menus animate in before they accept
# input, and a press that arrives during the animation is ignored.
#
# Typical transcript: FILE_MENU 8.3, VEHICLE_CLASS_SELECT 9.3, PILOT_SELECT
# 11.3, TEST_OVERVIEW 13.3, TEST_DETAILS 15.3, TEST_SETUP 17.3, TEST_UPDATE 17.4,
# RESULTS about 55.
